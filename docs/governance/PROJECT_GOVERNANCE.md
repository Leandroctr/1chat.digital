# Project Governance - 1chat.digital

## Regras de governanca

- Toda mudanca relevante deve atualizar documentacao.
- Todo bug deve entrar em `docs/knowledge/KNOWN-BUGS.md`.
- Toda decisao importante deve entrar em `docs/knowledge/DECISIONS.md`.
- Toda mudanca de risco medio ou alto deve ter rollback.
- Documentacao obrigatoria antes de grandes refatoracoes.

## Onde registrar

- Decisoes: `docs/knowledge/DECISIONS.md`
- Bugs: `docs/knowledge/KNOWN-BUGS.md`
- Estado atual: `docs/ai/CURRENT_STATUS.md`
- Regras para IA: `docs/ai/AI_RULES.md`
- Politica de mudanca: `docs/ai/AI_CHANGE_POLICY.md`
- Operacao: `docs/knowledge/OPERATION.md`
- Recuperacao: `docs/disaster-recovery/`

## Antes de grandes mudancas

1. Ler `START_HERE.md`.
2. Classificar risco.
3. Listar impacto.
4. Listar rollback.
5. Confirmar com o dono do projeto se risco for alto.
6. Atualizar documentacao.

## Principio central

Continuidade operacional vem antes de arquitetura ideal.
