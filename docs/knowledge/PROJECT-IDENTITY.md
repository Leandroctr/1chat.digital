# Project Identity - 1chat.digital

## Identidade

Confirmado por inspeção do código em origin/main:

- O projeto tem um site publico estatico.
- O projeto tem um bot WhatsApp baseado em Node.js/Express.
- O projeto tem painel admin proprio em `bot/public/`.
- O projeto usa planilha Excel como base de respostas.

Confirmado em produção pública:

- O servico publico se identifica como `1chat-bot` em `/health`.
- O modo publico reportado e `production`.

## Objetivo

Manter um atendimento WhatsApp operacional, com painel admin, fluxo de bot, atendimento humano e controle de dados criticos.

## Principios

- Estabilidade antes de novas funcionalidades.
- Dados e credenciais fora do Git.
- Documentacao fiel ao estado real.
- Mudancas pequenas e verificaveis.
- Operacao sensivel exige aprovacao explicita.
